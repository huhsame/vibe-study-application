## 미리 알면 좋아요 (선택)

📹 **참고 영상**
- [Claude Code 공식 소개](https://www.youtube.com/results?search_query=claude+code+tutorial) - Claude Code가 뭔지 10분 미리보기

📚 **기본 개념**
- 터미널(CLI)에서 명령어 입력해본 경험 (cd, ls 정도)
- AI한테 말로 시키면 코드가 나온다는 개념 이해

🔑 **유료 API (권장)**
- AI 이미지/영상/음성 생성을 위해 외부 API를 사용합니다
- Gemini API, ElevenLabs, Typecast, Sora 등 유료 API 키를 보유하신 분께 권장합니다
- 스터디 중 구체적인 세팅 방법을 안내해드립니다

💡 필수는 아니지만, 미리 보고 오시면 스터디가 더 수월해요!

## 이런 분께 추천해요

- 숏폼 드라마로 유튜브/틱톡 채널을 시작하고 싶은데 영상 제작은 해본 적 없는 분
- AI 도구(Sora, ElevenLabs 등)를 써봤지만 각각 따로 돌려서 비효율적인 분
- Claude Code를 실전 프로젝트에 적용해보고 싶은 개발자/비개발자
- 혼자서 매일 콘텐츠를 찍어내고 싶은 1인 크리에이터

## 이런 문제를 바이브코딩으로 해결해요

- **숏폼 드라마를 만들고 싶은데 혼자서는 시작조차 막막** → Claude Code로 세계관부터 스크립트, 이미지, 영상, 음성까지 AI로 생성
- **시리즈물은 캐릭터·스토리 일관성 유지가 어려움** → Claude Code로 세계관·캐릭터 설정을 관리하고 에피소드마다 자동 반영
- **AI 도구는 많은데 각각 따로 써야 해서 비효율적** → Claude Code 스킬로 Gemini, ElevenLabs, Typecast 등 여러 AI 도구를 한 번에 활용
- **매번 새 에피소드 만들 때마다 처음부터 다시 작업** → 한 번 만든 스킬을 재사용해서 새 에피소드를 빠르게 생성

## 바이브코딩으로 만드는 결과물

4주 후 가져갈 것:
- **숏폼 드라마 시리즈** - 세계관, 캐릭터, 스토리가 이어지는 나만의 시리즈 에피소드
- **AI 콘텐츠 생성 능력** - 스크립트, 이미지, 영상, 음성까지 AI로 직접 만드는 경험
- **재사용 가능한 Claude Code 스킬 세트** - 설정만 바꾸면 새 에피소드가 뚝딱 나오는 도구 모음

## 커리큘럼

### 1주차: 숏폼 드라마를 위한 Claude Code 스킬 & 에이전트 구성

**학습 목표**: Claude Code 환경을 구축하고, 숏폼 드라마 제작에 필요한 스킬과 에이전트를 설계하기

**주요 내용**
- Claude Code 설치 및 기본 사용법 익히기
- 스킬(Skill)과 에이전트(Agent) 개념 이해
- 숏폼 드라마 제작에 필요한 스킬 설계 (스크립트 생성, 이미지 생성, 음성 생성 등)
- AI API 연동 세팅 (Gemini API, ElevenLabs, Typecast 등)

**실습 과제**: 숏폼 드라마 제작용 Claude Code 스킬 & 에이전트 구성

**결과물**: 숏폼 드라마 제작용 스킬 & 에이전트 세트

---

### 2주차: 캐릭터 설계 & 시리즈 스토리라인 구성

**학습 목표**: 매력적인 캐릭터를 설계하고, 에피소드별 스토리라인을 구성하기

**주요 내용**
- 주인공 및 주요 캐릭터 설정 (성격, 외모, 관계, 갈등 구조)
- 캐릭터 간 관계도 설계
- 시리즈 전체 스토리라인 구성 (에피소드별 흐름 설계)
- 캐릭터·스토리 설정을 Claude Code 스킬로 만들기

**실습 과제**: 캐릭터 3명 이상 설정 + 5화 분량 스토리라인 구성

**결과물**: 캐릭터 설정 & 스토리라인 자동 생성 Claude Code 스킬

---

### 3주차: 에피소드 스크립트 & AI 이미지 생성

**학습 목표**: 스토리라인을 기반으로 에피소드별 스크립트를 생성하고, AI 이미지를 만들기

**주요 내용**
- 스토리라인 → 에피소드별 숏폼 스크립트 자동 생성
- 숏폼 스크립트 구조 이해 (3초 훅, 갈등, 반전, 다음 화 떡밥)
- 캐릭터 일관성을 유지하는 AI 이미지 생성 (Gemini API 등)
- 장면별 이미지 프롬프트 설계 & 자동 생성

**실습 과제**: 에피소드 2편 분량 스크립트 + 장면별 AI 이미지 생성

**결과물**: 스크립트 & 이미지 자동 생성 스킬

---

### 4주차: AI 영상·음성 생성 & 시리즈 완성

**학습 목표**: AI 영상과 음성을 생성하고, 시리즈 에피소드를 완성하기

**주요 내용**
- AI 영상 생성 도구 활용 (이미지 → 움직이는 영상)
- 캐릭터별 목소리 설정 & TTS 대사 생성 (ElevenLabs, Typecast 등)
- BGM 및 효과음 매칭
- 시리즈 에피소드 소스 완성 & 최종 점검

**실습 과제**: 시리즈 에피소드 2편 이상의 영상 + 음성 소스 완성

**결과물**: AI 영상·음성 소스가 포함된 숏폼 드라마 시리즈 에피소드

## 바이브코딩 도구 소개

**Claude Code**는 터미널에서 자연어로 코딩하는 Anthropic의 공식 CLI 도구입니다.
"숏폼 드라마 스크립트 만들어줘"라고 말하면 코드를 직접 쓰지 않아도 Claude가 스크립트를 생성하고, API를 연동하고, 영상을 편집하는 코드까지 만들어줍니다. 스킬과 에이전트 기능을 활용하면 복잡한 멀티스텝 작업도 명령 한 줄로 실행할 수 있어서, 코딩 경험 없이도 전체 영상 제작 파이프라인을 구축할 수 있습니다.
