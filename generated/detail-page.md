## 이런 분께 추천해요

- 숏폼 드라마로 유튜브/틱톡 채널을 시작하고 싶은데 영상 제작은 해본 적 없는 분
- AI 도구(Sora, ElevenLabs 등)를 써봤지만 각각 따로 돌려서 비효율적인 분
- Claude Code를 실전 프로젝트에 적용해보고 싶은 개발자/비개발자
- 혼자서 매일 콘텐츠를 찍어내고 싶은 1인 크리에이터

## 이런 문제를 바이브코딩으로 해결해요

- **숏폼 하나 만들려면 스크립트/촬영/편집/음악까지 전문 인력 필요** → Claude Code 하나로 스크립트부터 완성 영상까지 자동 생성
- **AI 도구는 많은데 각각 따로 써야 해서 파이프라인 연결이 안 됨** → 스킬과 에이전트로 Sora, ElevenLabs, ffmpeg 등 전체를 하나로 연결
- **콘텐츠는 매일 올려야 경쟁력인데 수작업으론 양산 불가능** → 자동화 파이프라인으로 "명령 한 줄 = 영상 한 편" 체계 구축
- **영상 제작 경험 없는 1인 창작자는 시작조차 막막** → 코드 한 줄 안 쓰고 자연어로 전체 파이프라인 구축

## 바이브코딩으로 만드는 결과물

4주 후 가져갈 것:
- **숏폼 드라마 자동 생성 파이프라인** - 스크립트 → 이미지 → 영상 → 오디오 → 편집 → 업로드, 전 과정이 자동으로 돌아가는 나만의 시스템
- **실제 업로드 가능한 숏폼 드라마 콘텐츠** - 직접 만든 파이프라인으로 생성한 진짜 콘텐츠
- **재사용 가능한 Claude Code 스킬/에이전트 세트** - 장르만 바꾸면 새 에피소드가 뚝딱 나오는 도구 모음

## 커리큘럼

### 1주차: Claude Code 세팅 & AI 스크립트 자동 생성

**학습 목표**: Claude Code 환경을 구축하고, 숏폼 드라마 스크립트를 AI로 자동 생성하기

**주요 내용**
- Claude Code 설치 및 기본 사용법 익히기
- 숏폼 드라마 스크립트 구조 이해 (3초 훅, 갈등, 반전)
- 프롬프트 설계로 장르별 스크립트 자동 생성
- 스크립트 생성을 Claude Code 스킬로 만들기

**실습 과제**: 로맨스/스릴러/일상 장르별 숏폼 스크립트 각 1편 자동 생성

**결과물**: 스크립트 자동 생성 Claude Code 스킬

---

### 2주차: AI 이미지·영상·오디오 생성 연동

**학습 목표**: 스크립트를 기반으로 이미지, 영상, 오디오를 AI로 자동 생성하기

**주요 내용**
- AI 이미지 생성 API 연동 (장면별 이미지 자동 생성)
- AI 영상 생성 도구 활용 (이미지 → 움직이는 영상)
- TTS로 나레이션/대사 자동 생성
- BGM 및 효과음 자동 매칭

**실습 과제**: 1주차 스크립트 기반으로 장면별 이미지 + 영상 + 음성 소스 생성

**결과물**: 멀티미디어 소스 자동 생성 스킬

---

### 3주차: 자동 편집 & 파이프라인 통합

**학습 목표**: 생성된 소스를 자동 편집하고, 전체 파이프라인을 하나로 연결하기

**주요 내용**
- 영상 클립 자동 이어붙이기 (ffmpeg 자동화)
- 자막 자동 생성 및 삽입
- 오디오 싱크 맞추기 및 믹싱 자동화
- 스크립트 → 완성 영상까지 전체 파이프라인 통합

**실습 과제**: 전체 파이프라인을 돌려서 숏폼 드라마 1편 완성

**결과물**: 원클릭 영상 생성 통합 파이프라인

---

### 4주차: 자동 업로드 & 파이프라인 완성

**학습 목표**: 완성 영상을 자동 업로드하고, 나만의 채널 운영 시스템 완성하기

**주요 내용**
- 유튜브/틱톡 자동 업로드 연동
- 썸네일 및 제목/설명/태그 자동 생성
- 에이전트로 "장르 입력 → 업로드"까지 원클릭 실행
- 나만의 스타일로 파이프라인 커스터마이징

**실습 과제**: 완성된 파이프라인으로 숏폼 드라마 2편 생성 후 실제 업로드

**결과물**: 숏폼 드라마 자동 생성 & 업로드 파이프라인 완성

## 바이브코딩 도구 소개

**Claude Code**는 터미널에서 자연어로 코딩하는 Anthropic의 공식 CLI 도구입니다.
"숏폼 드라마 스크립트 만들어줘"라고 말하면 코드를 직접 쓰지 않아도 Claude가 스크립트를 생성하고, API를 연동하고, 영상을 편집하는 코드까지 만들어줍니다. 스킬과 에이전트 기능을 활용하면 복잡한 멀티스텝 작업도 명령 한 줄로 실행할 수 있어서, 코딩 경험 없이도 전체 영상 제작 파이프라인을 구축할 수 있습니다.
