🔑 **유료 API (권장)**

## 이런 분께 추천해요

- 숏폼 드라마로 유튜브/틱톡 채널을 시작하고 싶은데 영상 제작은 해본 적 없는 분
- AI 도구(Sora, ElevenLabs 등)를 써봤지만 각각 따로 돌려서 비효율적인 분
- Claude Code를 실전 프로젝트에 적용해보고 싶은 개발자/비개발자
- 혼자서 매일 콘텐츠를 찍어내고 싶은 1인 크리에이터

## 이런 문제를 바이브코딩으로 해결해요

- **시리즈물은 캐릭터·스토리 일관성 유지가 어려움** → Claude Code로 세계관·캐릭터 설정을 관리하고 에피소드마다 자동 반영
- **숏폼 하나 만들려면 스크립트/촬영/편집/음악까지 전문 인력 필요** → Claude Code 하나로 스크립트부터 완성 영상까지 자동 생성
- **AI 도구는 많은데 각각 따로 써야 해서 파이프라인 연결이 안 됨** → 스킬과 에이전트로 Gemini, ElevenLabs, Typecast, ffmpeg 등 전체를 하나로 연결
- **시리즈 콘텐츠는 꾸준히 올려야 경쟁력인데 수작업으론 양산 불가능** → 자동화 파이프라인으로 "명령 한 줄 = 에피소드 한 편" 체계 구축

## 바이브코딩으로 만드는 결과물

4주 후 가져갈 것:
- **숏폼 드라마 시리즈** - 캐릭터와 스토리가 이어지는 여러 에피소드로 구성된 나만의 시리즈
- **시리즈 자동 생성 파이프라인** - 세계관 설정 → 스크립트 → 영상 → 편집 → 업로드, 전 과정이 자동으로 돌아가는 시스템
- **재사용 가능한 Claude Code 스킬/에이전트 세트** - 설정만 바꾸면 새 에피소드가 뚝딱 나오는 도구 모음

## 커리큘럼

### 1주차: Claude Code 세팅 & 세계관·캐릭터 설계

**학습 목표**: Claude Code 환경을 구축하고, 숏폼 드라마 시리즈의 세계관과 캐릭터를 설계하기

**주요 내용**
- Claude Code 설치 및 기본 사용법 익히기
- 숏폼 드라마 시리즈 기획: 장르 선택, 세계관 설정
- 주인공 및 주요 캐릭터 설정 (성격, 관계, 갈등 구조)
- 시리즈 전체 스토리라인 구성 (에피소드별 흐름 설계)
- 캐릭터·스토리 설정을 Claude Code 스킬로 만들기

**실습 과제**: 나만의 시리즈 세계관 + 캐릭터 3명 이상 설정 + 5화 분량 스토리라인 구성

**결과물**: 시리즈 기획서 자동 생성 Claude Code 스킬

---

### 2주차: 에피소드 스크립트 & AI 소스 생성

**학습 목표**: 스토리라인을 기반으로 에피소드별 스크립트를 생성하고, 이미지·영상·음성 소스를 만들기

**주요 내용**
- 1주차 스토리라인 → 에피소드별 숏폼 스크립트 자동 생성
- 캐릭터 일관성을 유지하는 AI 이미지 생성 (Gemini API 등)
- AI 영상 생성 도구 활용 (이미지 → 움직이는 영상)
- 캐릭터별 목소리 설정 & TTS 대사 생성 (ElevenLabs, Typecast 등)

**실습 과제**: 시리즈 에피소드 2편 분량의 스크립트 + 이미지 + 영상 + 음성 소스 생성

**결과물**: 에피소드 멀티미디어 소스 자동 생성 스킬

---

### 3주차: 자동 편집 & 시리즈 파이프라인 통합

**학습 목표**: 생성된 소스를 자동 편집하고, 시리즈 전체를 관통하는 파이프라인을 구축하기

**주요 내용**
- 영상 클립 자동 이어붙이기 (ffmpeg 자동화)
- 자막 자동 생성 및 삽입
- 오디오 싱크 맞추기 및 믹싱 자동화
- 에피소드 간 연결 (인트로/아웃트로, 다음 화 예고)
- 세계관 설정 → 스크립트 → 완성 영상까지 전체 파이프라인 통합

**실습 과제**: 전체 파이프라인을 돌려서 시리즈 에피소드 2편 완성

**결과물**: 시리즈 영상 생성 통합 파이프라인

---

### 4주차: 시리즈 완성 & 채널 운영 자동화

**학습 목표**: 시리즈를 완성하고, 자동 업로드까지 나만의 채널 운영 시스템 갖추기

**주요 내용**
- 유튜브/틱톡 자동 업로드 연동
- 시리즈 썸네일·제목·설명·태그 자동 생성 (에피소드 넘버링 포함)
- 에이전트로 "장르 입력 → 시리즈 생성 → 업로드"까지 원클릭 실행
- 나만의 스타일로 파이프라인 커스터마이징

**실습 과제**: 완성된 파이프라인으로 시리즈 에피소드 3편 이상 생성 후 실제 업로드

**결과물**: 숏폼 드라마 시리즈 자동 생성 & 업로드 파이프라인 완성

## 바이브코딩 도구 소개

**Claude Code**는 터미널에서 자연어로 코딩하는 Anthropic의 공식 CLI 도구입니다.
"숏폼 드라마 스크립트 만들어줘"라고 말하면 코드를 직접 쓰지 않아도 Claude가 스크립트를 생성하고, API를 연동하고, 영상을 편집하는 코드까지 만들어줍니다. 스킬과 에이전트 기능을 활용하면 복잡한 멀티스텝 작업도 명령 한 줄로 실행할 수 있어서, 코딩 경험 없이도 전체 영상 제작 파이프라인을 구축할 수 있습니다.
